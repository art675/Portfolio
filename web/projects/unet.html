03 AUTONOMY / PROJECT 14

U-NET SEMANTIC LANE SEGMENTATION

Engineering portfolio case study

Project 14 · Section 1

What Semantic Segmentation Is

This project asked a different perception question than object detection: instead of locating a sign with one bounding box, a U-Net convolutional neural network classified every pixel in the camera image as line_left, line_right, or background.

That pixel-level output can preserve the shape and continuity of road markings, making it useful for downstream lane understanding.

ONE IMAGE BECOMES A PIXEL MAP

The training label is not a single category for the whole image.

It is an image-sized mask in which each pixel carries one class ID.

During inference, U-Net predicts the same kind of mask from a new camera frame.

Project 14 · Section 2

Bad Label -> Bad Statistics -> Baseline Training

Before changing the neural network, the dataset itself was audited.

A histogram of labeled pixels revealed three extreme right-lane outliers.

Inspection traced them to one incorrectly annotated frame and its augmented copies.

The page therefore follows a simple sequence: distribution anomaly bad mask baseline training behavior.

BAD ANNOTATION

What the histogram revealed.

Most right-lane masks occupied a compact pixel-count range, but three samples contained dramatically more labeled pixels than the rest of the dataset.

Why those outliers existed.

One frame incorrectly labeled a large image region as line_right.

Augmented copies inherited the same error, turning one annotation mistake into three outliers.

BASELINE TRAINING

WHY THIS MATTERED The model could still report reasonable aggregate metrics while learning from a flawed label distribution.

Cleaning the annotations therefore had to come before comparing architectures or hyperparameters.

Training setup Batch 4, learning rate 0.001, maximum 100 epochs.

Early stopping ended the run at 34 epochs after validation loss stopped improving.

Project 14 · Section 3

Cleaned Data + Best Iou Run

The mislabeled frame and its augmented copies were removed before the next training run.

The purpose was not simply to improve the reported score, but to restore a physically plausible right-lane distribution.

The cleaned dataset was then retrained with the same batch size and learning rate, allowing the effect of correcting the labels to be evaluated directly.

WHAT CHANGED?

The three extreme right-lane samples are gone.

Instead of extending to nearly 15,000 labeled pixels, the cleaned line_right distribution now occupies a range comparable to the left-lane samples.

This changes what the experiment means.

The network is no longer being evaluated against a label distribution distorted by one annotation error and its augmented copies.

The next run therefore asks a controlled question: what happens when the same model is trained on cleaner data?

RETRAINING THE SAME MODEL ON CLEANER DATA

Same basic training setup, cleaner labels.

Batch 4, LR 0.001, with early stopping at 41 epochs.

This run produced the strongest validation and test IoU of the four experiments.

The remaining question was whether a good aggregate IoU also produced a visually trustworthy lane mask.

Project 14 · Section 4

Why More Training Was Tested

A test prediction still contained small false-positive right-lane pixels.

To investigate whether this came from excessive training, batch size was increased from 4 to 8 and two additional training lengths were examined.

The key question was whether reducing training would remove the artifact without sacrificing useful lane segmentation.

WHAT THE EXPERIMENT SHOWED

The 20-epoch model had not finished improving, while the 47-epoch model recovered much of the IoU and reduced test loss.

Because the same visible artifact persisted even when the training length changed, the evidence did not support the simple explanation that overfitting alone caused the false-positive lane fragments.

Visual inspection still mattered alongside the metrics.

Project 14 · Section 5

Same Scene, Three Model Predictions

IoU and loss summarize millions of pixel decisions into single numbers.

These prediction images show what those numbers can hide: the dominant lane structure is usually recovered, while small right-lane fragments can appear near reflective or high-contrast regions.

Viewing the same scene across the three runs makes the progression easier to judge.

HOW TO READ THESE IMAGES

The cleaned 41-epoch model gives the strongest lane overlap numerically, but the shorter batch-8 experiment does not eliminate the false-positive artifact.

The report attributes part of the erroneous right-lane prediction to glare in the scene.

That makes the qualitative comparison essential: good segmentation is not only a high score, but a physically sensible mask.

Intersection over Union (IoU) measures the overlap between a predicted segmentation mask and the labeled ground truth.

A higher IoU means the model is assigning more pixels to the correct class while avoiding unnecessary false-positive regions.

For semantic segmentation, IoU is more informative than raw accuracy because the background class dominates most of the image.

A model could achieve high pixel accuracy by predicting background nearly everywhere while still missing the lane markings that matter for autonomy.

Training loss describes how strongly the network is penalized during optimization, while validation loss checks whether that learned behavior generalizes to data it did not directly train on.

When training improves but validation performance stops improving, the model may be beginning to overfit.

These images also show why quantitative metrics need a qualitative check.

Two runs can produce similar IoU values while making very different mistakes.

A small false-positive fragment can be numerically minor but still physically misleading if it appears where no lane exists.

Key machine-learning ideas shown here: class imbalance, semantic segmentation, train/validation behavior, generalization, early stopping, overfitting, and qualitative model validation.

Project 14 · Section 6

Simple Results + Physical Context + Resources

The final comparison did not produce one universally ``best'' model.

The clean-data batch-4 run achieved the strongest IoU, while the longer batch-8 run achieved the lowest test loss among the cleaned-data experiments and reduced the visible artifact.

The useful conclusion was therefore a model-selection tradeoff, not simply a ranking.

PHYSICAL CONTEXT

The segmentation study was developed for the same physical autonomous-vehicle environment: camera imagery becomes a lane mask that can support higher-level road interpretation and control.
